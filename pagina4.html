  • Dominio:

    En HTML, el "dominio" no es un elemento o etiqueta específica, sino un término general que se refiere a la dirección del sitio web.

  • Subdominio:

    Un subdominio es una nueva dirección o URL que reemplaza el "www" de tu dominio por la palabra que desees.

  • URL:

    URL significa Uniform Resource Locator (Localizador de Recursos Uniforme). Una URL no es más que una dirección que es dada a un recurso único en la Web.

  • DNS:

    En HTML, DNS se refiere al Sistema de Nombres de Dominio (Domain Name System), una parte fundamental de la web que permite a los usuarios acceder a sitios web

  • Hosting:

    Un hosting es un servicio de alojamiento para sitios web.

  • FTP:

    FTP (del inglés File Transfer Protocol, Protocolo de transferencia de archivos) fue el protocolo estándar durante muchos años para transferir archivos entre equipos a través de Internet.

  • HTTP:

    HTTP, que significa Hypertext Transfer Protocol (Protocolo de Transferencia de Hipertexto), es el protocolo que permite la comunicación y transferencia de datos entre un cliente (por ejemplo, un navegador web) y un servidor web, especialmente para transferir archivos como documentos HTML.

  • HTTPS:

    HTTPS es la versión segura de HTTP (Hypertext Transfer Protocol). La "S" adicional indica que la comunicación entre el navegador y el servidor web está cifrada, lo que protege la información transmitida, como contraseñas o datos personales, de ser interceptada por terceros.

  • W3C:

    W3C, que significa World Wide Web Consortium, es una organización internacional que desarrolla estándares y recomendaciones para la Web,

  • UTF-8:

    En HTML, UTF-8 es un estándar de codificación de caracteres que permite que un sitio web muestre correctamente caracteres de cualquier idioma, incluyendo emojis y caracteres especiales
